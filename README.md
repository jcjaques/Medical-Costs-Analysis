Data Source:
The dataset is sourced from Kaggle, but comes from the book Machine Learning with R by Brett Lantz, which provides an introduction to machine learning using R.  Although the dataset is fictional, it will be used to for this project explore factors that contribute to higher medical costs.  The dataset provides 1,338 records of medical charges for adults 18-64.  Each Entry contains information about each insurance contractor including factors that could lead to higher medical charges.  

The dataset aggregates information about each insurance contractor including: age, gender, bmi (body mass index), number of dependent children, smoking status, region, and medical charges.
The data can be accessed here:

https://www.kaggle.com/datasets/mirichoi0218/insurance

Data Limitations:
1.	Limited Variables – The data shows factors that could contribute to higher medical charges for insurance contractors.  However, many more variables could contribute to medical charges that are not part of the dataset.
2.	Lack of Context – The data does not give specific years when the data was collected and therefore might lack relevance for the present.
3.	Synthetic Dataset – although created to mimic the characteristics and patterns of real-world data, the data does not represent actual insurance contractors.

Why This Data?
I choose this data because I liked the idea of exploring the contributing factors of each insurance contractor to their corresponding medical charges.  Although a synthetic dataset, I liked the idea of analysis relationships between the variables outside of the medical charges. Such as in what region contain the most smokers or highest number of individuals with a high BMI.
I felt this would dataset would allow me to utilize some of the skills I used in this program not to mention explore information within healthcare, an industry I have worked in.

Ethical Considerations:
Due to the dataset being synthetic, any insights derived should not be used to make real-life conclusions.  All insights from this data, will be used solely for this project to show case data analytic skills learned.
